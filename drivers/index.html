Find where a driver officially comes from. Each record shows its source, evidence, version and date only when the source states them, and a direct link only when it is official and stable. Nothing is hosted or run here.

Identify hardware from hardware IDs

Paste hardware IDs from Device Manager (Properties, Details, Hardware Ids) or the JSON report from the read-only script below. The page matches the vendor part of each ID to the vendor directory and to records that state the same ID.

The report script is read-only: it lists the computer's maker, model, Windows build and each device's name and hardware IDs. It collects no serial numbers, user names or host name, and nothing is uploaded; matching runs in this page. Download Get-AntoHardwareReport.ps1

About ANTO-LTG

An open technician platform: a software catalog, a driver source finder and a WinGet script generator. It indexes official sources and never hosts or runs installers.
