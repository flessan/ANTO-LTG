    What this project promises (and does not)
    • Every record cites the page it came from and the date it was read.
    • Versions, dates, hashes and Windows compatibility are shown only when a source states them; otherwise they say "unknown".
    • Nothing is installed from your browser, and no installer or driver binary is hosted or mirrored here.
    • "Pending review" means no maintainer has verified the record yet; it is a research index, not a guarantee of safety.
    • It is a static set of JSON files rebuilt from Git, not a live driver database or a real-time API.

    About ANTO-LTG

    An open technician platform: a software catalog, a driver source finder and a WinGet script generator. It indexes official sources and never hosts or runs installers.
